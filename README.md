# Linked List

Through this project, I gained practical experience in:

- Understanding the core concepts of a linked list.
- Implementing the foundational structure of a linked list.
- Developing essential methods for interacting with the list, such as:
  - Adding new nodes (at the beginning, end, or a specific position).
  - Removing existing nodes.
  - Traversing and displaying the list elements.
  - Searching for specific elements within the list.

This project served as a valuable learning exercise to solidify my understanding of this fundamental data structure.
